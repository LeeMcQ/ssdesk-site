Sabbath Service Desk companion

One small program for the PC that runs the service. It links that PC to the other devices on the church Wi‑Fi or network, with no internet needed:

  • OBS on another computer: the lower third and the slides follow Sabbath Service Desk.
  • Phones as a remote, a TV or second PC as the screen, and stage screens.
  • Videos from the PC’s Videos folder, and exact PowerPoint conversion (with LibreOffice).

Set it up on Windows

  1. Download the Windows program above on the PC that runs the service.
  2. Double‑click sda-sabbath-windows-x64.exe. Windows may say it “protected your PC”: click More info → Run anyway (the program is not signed by a company).
  3. When Windows asks about network access, tick Private networks and click Allow. Without this, other computers cannot reach it.
  4. Sabbath Service Desk opens in your browser at http://localhost:7777. Use Sabbath Service Desk from this tab during the service (not the website) and keep it open.
  5. Optional: to get a Start‑menu and desktop shortcut, run it once with --install (PowerShell: .\sda-sabbath-windows-x64.exe --install).

Connect OBS on the second computer

  1. Make sure both computers are on the same Wi‑Fi or network.
  2. In Sabbath Service Desk (the localhost:7777 tab) open Tools → Stream. The box “OBS on another computer” shows two addresses with this PC’s network address in them.
  3. Click Copy lower third address. Send it to the OBS computer (e‑mail, WhatsApp, or type it — it looks like http://192.168.1.20:7777/obs.html?via=lan&mode=lower).
  4. In OBS: Sources → + → Browser, paste it as the URL, set Width 1920, Height 1080, press OK, and drag it above the camera.
  5. Show a Bible verse in Sabbath Service Desk: the words appear in OBS. For full‑screen slides, add the Presentation address the same way in its own scene.

OBS says “waiting for the media desk”? The OBS link works, but Sabbath Service Desk is not open at http://localhost:7777 on the companion PC. Open it there (not the website) and keep it open. OBS shows nothing at all? Open the same address in a browser on the OBS computer; if it does not load, allow the companion through Windows Firewall on private networks.

Emergency copy on a USB stick

If the church PC’s browser ever loses its stored copy of Sabbath Service Desk (a cleaned disk, a reset browser, a new PC), a USB stick gets the service going in a minute, with no internet:

  1. Copy sda-sabbath-windows-x64.exe (above) to a USB stick. It contains the whole app: Bibles, hymns, hymn music, fonts.
  2. In Sabbath Service Desk, Settings → Backup → Back up or move to another device → save to a file, and put that file on the same stick. Plans, slides, banners and your own hymns are in the backup, not in the program.
  3. On the day: plug in the stick, double‑click the program, and Sabbath Service Desk opens at http://localhost:7777. Restore the backup file there if you need your plans and slides.
  4. Make a new backup on the stick every few weeks (or after big changes), and update the program when the website has a new one.

The web app zip (above, if listed) is the same app as plain files, for hosting on your own web server or running with sda-sabbath-windows-x64.exe --app-dir FOLDER. It does not open by double-clicking index.html: browsers do not run apps from files.

Raspberry Pi or Linux

Download the Linux file, then in a terminal: chmod +x sda-sabbath-linux-* and run it. Open http://localhost:7777.

Built automatically every time the website is updated, so it always matches the website.
